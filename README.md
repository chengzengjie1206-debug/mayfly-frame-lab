# Mayfly 工具站

Mayfly 是一个本地优先的中文网页工具，用来把视频素材整理成游戏可用的序列帧与透明 PNG 资源，适合 Unity、Godot 以及独立游戏素材流程。

## 在线使用

直接访问：

https://chengzengjie1206-debug.github.io/mayfly-frame-lab/

普通用户无需克隆仓库、无需本地部署，打开网站即可使用。

## 主要功能

- 本地上传或拖拽视频
- 裁剪主体区域，去掉留白和无关画面
- 取色抠图，预览抠图结果、Alpha 蒙版和纯底色效果
- 生成序列图和透明单帧 PNG
- 动画预览与导出验收

## 使用说明

1. 打开在线工具站
2. 进入控制台并上传本地视频
3. 调整裁剪范围、抽帧参数和抠图参数
4. 预览序列图或动画效果
5. 导出 PNG 序列图或透明单帧 ZIP

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 自行部署

这一部分只给想二次开发或自己托管的人使用。普通用户直接访问在线站点即可。

### GitHub Pages

项目已包含 GitHub Actions 部署工作流。

1. 将项目推送到你自己的 GitHub 仓库
2. 在 `Settings -> Pages` 中把来源设为 `GitHub Actions`
3. 推送到 `main` 分支后，仓库中的工作流会自动构建并发布站点

### 其他静态托管平台

项目使用相对路径 `base`，也可以直接部署到 Netlify、Vercel 或其他静态托管平台。
